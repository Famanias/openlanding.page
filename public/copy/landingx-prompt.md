# Rebuild Landing X — a creative skill for landing pages

Build a complete responsive landing page for Landing X, the public-facing name of the create-landing-template agent skill. The site should showcase a diverse collection of real landing-page templates as its main attraction. Use impeccable.style only as inspiration for its restrained editorial typography, precise interface details, and motion; do not reproduce its layout, artwork, words, or before-and-after component.

## Identity

Use #F1F0E8 chalk as the primary canvas, #FAF9F3 warm white for the project index, #222622 ink for type and the approach section, #B53E2B vermilion for actions and emphasis, with #E4E6DD fog and #899385 sage for supporting surfaces. Derive tints from these colors. Use Barlow Condensed for display, Manrope for body, and IBM Plex Mono for labels. Create an original crossed-X mark.

## Composition

Begin with a full-width typographic masthead and a small strip of three project previews, then move directly into a substantial project index and 16:9 gallery. Give the work enough space to be the focus. Show Avel, Pello, Satsuma, Firstday, Rill, and Hiyas as six projects, using the supplied 16:9 project screenshots. Include accessible category filters and links to the existing local examples. Follow with a concise explanation of the skill, a three-step brief-to-build sequence, a copyable starter brief, and a footer. Avoid the reference website's side-by-side hero and demo layout.

## Interaction and quality

Use the gallery filter and staggered project sheets as the signature interaction. Use subtle state changes, visible focus, restrained motion, and a scroll-progress indicator. All content must be visible without JavaScript and under reduced motion. The copy button should report success or failure honestly, while the brief remains selectable. Do not claim a fake install command or collect user data. Include metadata, a favicon, a standalone HTML version, responsive layouts, and meaningful browser tests.
