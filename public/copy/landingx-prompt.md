# Rebuild Landing X — a creative skill for landing pages

Build a complete responsive landing page for Landing X, the public-facing name of the create-landing-template agent skill. The site should showcase a diverse collection of real landing-page templates as its main attraction. Use impeccable.style only as inspiration for its restrained editorial typography, precise interface details, and motion; do not reproduce its layout, artwork, words, or before-and-after component.

## Identity

Use #BEAA97 as the primary light brown canvas and #815751 as the complementary rust. Use #E5DDD7, #E8EEEE, #4B3C2E and #826851 for supporting surfaces and text. Derive tints from these colors and darken the ink for small text on light brown. Use Barlow Condensed for tall, light display type, Manrope for body, and IBM Plex Mono for labels. Create an original crossed-X mark.

## Composition

Begin with a full-width typographic masthead and a small strip of three project previews, then move directly into a substantial project index and 16:9 gallery. Give the work enough space to be the focus. Show Avel, Pello, Satsuma, Firstday, Rill, and Hiyas as six projects, each with a clearly labeled image placeholder until the user supplies its screenshot. Include accessible category filters and links to the existing local examples. Follow with a concise explanation of the skill, a three-step brief-to-build sequence, a copyable starter brief, and a footer. Avoid the reference website's side-by-side hero and demo layout.

## Interaction and quality

Use the gallery filter and staggered project sheets as the signature interaction. Use subtle state changes, visible focus, restrained motion, and a scroll-progress indicator. All content must be visible without JavaScript and under reduced motion. The copy button should report success or failure honestly, while the brief remains selectable. Do not claim a fake install command or collect user data. Include metadata, a favicon, a standalone HTML version, responsive layouts, and meaningful browser tests.

## Screenshots

Do not generate project images. The six user-supplied 16:9 filenames and processing instructions are in docs/image-prompts/landingx.md. Use labelled, compositionally intentional placeholders until those assets are added.
