# Rebuild Assemblage

Build the Assemblage landing page in Next.js 16 App Router, React 19 and TypeScript. It is a mixed media material study for independent brands. The primary action is **Request a material study**.

Use Manrope with Geist Mono for utility labels. Use only these palette colours: paper `#F6F0E8`, ink `#1E1D1B`, sand `#E2D8C9`, vermilion `#D95F3F`, teal `#1D6C63`, ochre `#E7C65A`, plum `#8F4E70`. Use flat backgrounds, layered collage shapes, paper shadows, tape strips, registration marks and no stock imagery.

Sections are a floating header, collage hero, four benefits, two line word by word tagline reveal, three step method, interactive material index, proof cards, six question FAQ, local request form with validation and success state, and footer. The material index is the signature: selecting Paper, Ink, Image or Signal raises that layer and changes the detail copy. Use IntersectionObserver for one time reveals, complete keyboard focus states, pressed button feedback and reduced motion fallbacks. Keep all content visible with JavaScript disabled. Keep imports inside `src/app/(assemblage)/`.
