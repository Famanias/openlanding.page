# Prompt: rebuild HANDOFF

Build a Next.js 16 App Router + React + TypeScript + Tailwind CSS v4 conversion landing page for a fictional outsourcing company called HANDOFF. Its positioning is “Good work, routed well.” It helps small businesses qualify, match and manage the client work they can actually take on.

Use a warm dotted paper canvas, near-black ink, signal orange, route blue, pass green and hairline beige. Use DM Serif Display for large editorial headlines, Geist for body and Geist Mono for labels. The page should look like a polished Webflow or WordPress marketing site: modular sections, compact nav, CMS-like cards, visible section labels, clear buttons and a practical lead form.

The central mechanic is a scroll-driven pipeline: INQUIRY → QUALIFIED → MATCHED → MANAGED → DONE. As each stage enters the viewport, its marker activates, the orange rail fills, and a HANDOFF ticket appears. The form asks for name, work email and service lane, validates locally, then shows “Brief received” without making a network request.

Sections: sticky header, hero with CSS dispatch desk illustration, gap statement, pipeline route, proof metrics, service lanes, fit check, dark close form, footer. Keep it responsive at 390px, keyboard accessible, and reduced-motion safe. No photos or external media are required.
