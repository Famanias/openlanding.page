# Prompt: rebuild “LOOPHOUSE” (neighborhood borrow landing page)

Build a one-page Next.js App Router + React + TypeScript + Tailwind CSS v4 landing page for LOOPHOUSE, a neighborhood tool library that matches people with nearby hosts.

Use a warm paper background `#EFF3E4`, deep ink `#17272A`, brick red `#2F6F67`, and ochre `#E3A52A`. Use DM Serif Display for display headings, Work Sans for body copy, and IBM Plex Mono for labels. The tone should feel local, useful, and hand-made.

The page should tell one service story in order: hero promise, four-step borrow route, two service options, an interactive distance-and-price calculator, local maker profiles, a people/metrics section, FAQs, and a final borrow intake CTA. Use CSS illustration for the route map and a warm editorial layout with ruled rows, no generic SaaS cards, and no glassmorphism.

Use IntersectionObserver for restrained reveals, keep controls keyboard accessible, and respect `prefers-reduced-motion`. The calculator is client-only and must never send a network request.
