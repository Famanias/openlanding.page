# HIYAS mountain relief artwork

These fourteen reliefs are adaptations of photographs of the actual mountains. Each SVG contains nine traced tonal layers, a transparent skyline and a fading foreground. The rock strata, gullies, snowfields, ice terraces and adjoining ridges come from the source photograph. Crops preserve its aspect ratio. Only HIYAS blue (`#0B2A4A`) and white (`#FFFFFF`) are used, with opacity for intermediate tones.

Changes to each source: sky removed; cropped; converted to luminance; tonal contours vectorized and simplified; recolored blue/white; foreground faded. These artwork derivatives retain the respective source licenses below. Those licenses apply to the artwork, not to the application source code.

The UI overlays separate SVG itinerary lines and dynamic camp markers. They are planning schematics; the photographic perspective is recorded per peak and is not a surveyed projection of the route.
