# VECTOR/90 — runtime maps for systems in motion

## Concept

VECTOR/90 is a developer-tool landing page presented like an early 3D workstation: a wireframe runtime object floats above a receding grid, terminal readouts label the scene, and the scroll moves through the model.

## Palette and type

- Black `#030706`: horizon and primary surface
- Deep green `#071713`: terminal panels
- Cyan `#51F6D3`: wireframe, rules and interface copy
- Signal green `#B8FF57`: active state and primary emphasis
- UI type uses a system monospace stack with hard, pixel-era spacing.

## Motion

- A procedural Three.js scene renders a grid floor, wireframe icosahedron, torus rings, satellite and particle field.
- Scroll progress changes camera distance, object rotation and world elevation.
- Copy reveals use opacity and translateY only. Reduced motion leaves the scene legible and removes reveal movement.

## Sections

1. Hero: “Make the invisible stack visible.” with readouts and an initialize CTA.
2. System: dependency map and terminal trace.
3. Runtime: map, replay, resolve.
4. Signal: operational metrics and protocol link.
5. Access: private beta CTA.
