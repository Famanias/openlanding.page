# Prompt: rebuild NOMI

Build a Next.js 16 App Router + React + TypeScript + Tailwind CSS v4 landing page for fictional NOMI, a calm mobile operating system for independent tutoring studios. Use a graphite navy glassmorphism environment, DM Serif Display, Geist and Geist Mono, with periwinkle and cyan accents. Do not copy Apple marks or screenshots.

The signature mechanic is a scroll-controlled phone launch. As the visitor scrolls through the launch section, the floating phone unlocks Inbox, Schedule, Progress and Payments. A tab rail can also change states. The page includes a hero, phone launch, capability cards, studio value section, plan card, local walkthrough form and footer.

Use CSS/DOM/SVG only; no photos or external media. Add rounded translucent cards, backdrop blur, soft borders, depth shadows, focus states, hover lifts, press states and reduced-motion fallbacks. The form should show a local success message without a network request.
