# Prompt: rebuild "OPENHOUSE" (conversion landing page for small businesses)

Build a landing page in Next.js App Router + React + TypeScript for the fictional conversion studio OPENHOUSE. The page has one job: book a 20-minute growth call for an owner-led small business.

The central idea is a lit front door. The hero contains a compact threshold form. Visitors choose one goal — fill a calendar, capture enquiries, or sell one service — then enter only their name and email. A valid local submission makes the threshold light and status dot settle open. The template must state that no request was sent because the form has no endpoint yet.

Use one wordmark, one filled primary button recipe, no navigation menu, no invented testimonials, logos, metrics, quotes, or photos. Sections: hero and form, what the call clears up, fit for service businesses / local shops / specialist practices, the welcome-listen-invite process, and a final form with a sticky booking action.

Use the palette from `tokens.css`: paper `#F7F2E9`, ink `#171414`, paper steps `#EEE6D9` and `#E6DACB`, cotton `#FFF9F0`, desk `#EDE5DA`, board `#344A3E`, terracotta `#D86B4A`, deep terracotta `#A9472E`, muted `#6B6359`, rules `#D7CDBF` and `#C7B9A8`. Use DM Sans for display and body and Geist Mono only for utility text.

Motion is organic and analog: unfurl and settle. Use a staged hero, mask-rise headings, drawn rules, paper-settle cards, a single requestAnimationFrame scroll progress line, and the threshold light as the signature moment. Content must be visible with JavaScript disabled and with `prefers-reduced-motion: reduce`. Animate only transform, opacity and clip-path for reveals; controls may transition colour and transform. Every interactive element needs hover, focus-visible, active and disabled states. Keep labels sentence case and avoid eyebrow text, tracked capitals, middle-dot metadata, and card-inside-card layouts.
