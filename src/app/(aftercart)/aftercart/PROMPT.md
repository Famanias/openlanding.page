# Prompt: rebuild AFTERCART — Shopify care after launch

Build an isolated Next.js 16 App Router + React 19 + TypeScript + Tailwind CSS v4 landing template for a fictional Shopify care partner called AFTERCART. The audience is small owner-led Shopify shops. The one conversion goal is booking a care call through a local-only demo form; never send a network request.

The central idea is that a shop is a living system, so the page is a pastel store health console whose signals rebalance as a visitor explores the care tracks. Use a warm paper canvas, rounded 6–10px geometry, merchant-tool and packaging-label cues, and a layered dot-grid background. Palette: ink #4C4668, paper #FFF7F3, lilac #DCCFF4, mint #BFE7D3, peach #FFCCB8, butter #F5E8A7, sky #BFD8F0. Use Manrope for display, Inter Tight for body, and JetBrains Mono for utility labels through next/font/google.

Sections: sticky header; hero with “Keep your shop ready.” and a console preview; interactive Store Health; four care tracks (Conversion, Merchandising, Speed, Retention); a visible work log; three-step care rhythm; local booking form; FAQ and footer. Selecting a track updates a tested pure state model, score ring, signal bars, status copy, active ticket, and aria-live readout. Unknown ids are ignored. The static page still contains all copy and the form without JavaScript.

Motion is expressive technical/cinematic with the verbs scan and reveal. Use a staggered hero load, mask-rise headings, drawn rules, clip-safe panel wipes, card lifts, button fill wipes, and one rAF scroll progress line. The signature moment is the console rebalancing after selection. Use transform, opacity, and clip-path for movement, visible focus rings, press scale .97, and reduced-motion/no-JS fallbacks. Test the console math, form validation, motion helpers, reduced motion, keyboard controls, mobile layout, and local success. Keep all files under src/app/(aftercart), register all gallery points, and use only original SVG/CSS interface art without photos or video.
