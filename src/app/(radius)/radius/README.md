# RADIUS template

RADIUS is an urban electric-bicycle concept page at `/templates/radius`. The build sheet lets visitors select a frame finish, a tire illustration and independently toggle the rear rack, basket and lights. Accessory and tire details are illustrative SVG overlays on matched side-profile images.

The street plan is a simulation, not a test of bicycle performance. The interest form is a local interaction: it does not transmit or save the entered details and does not place an order. Product pricing, availability and performance specifications are intentionally unspecified.

The images were supplied by the user; provenance and replacement notes are in `docs/image-prompts/radius.md`. To regenerate responsive local image variants, run `npm run images -- radius`. The copyable design brief is in `PROMPT.md`.
