# AMAOTO rebuild brief

Build an isolated Next.js App Router template for the fictional wagasa atelier AMAOTO, route `/amaoto`. Read the installed Next documentation before modifying framework code. Keep the existing copy and brand: sumi `#1A1613`, washi `#F4ECDD`, sakura `#F2B8C6`, deep sakura `#D9748F`, vermilion `#C8412B`, gold `#B8923A`, indigo `#2B3A55`; Shippori Mincho, Zen Kaku Gothic New, DM Mono. Tints must derive from this palette.

The umbrella leads the whole page. Reconstruct a 40-rib procedural wagasa from the four supplied references, including a narrow pleated closed state, bowed bamboo ribs, fixed-length stretchers, sliding runner, paper gores, rim lashings, diamond lacing, woven collar and turned cap/handle. Use `model/rig.ts` as the pure kinematic source. Reuse instanced geometry and mutate buffers; never rebuild cylinders each frame. Keep a typed runtime exposing `setOpen`, `setExplode`, `setSpread`, `setPose`, `setHighlight`, `setSun`, `setCanopy`, `update`, `tick` and `dispose`. Paper has painted per-gore motifs, separate fibre maps, simulated backlight and a 900 ms radial dye transition; no transmission pass.

A GSAP ScrollTrigger director with fine-pointer Lenis scrolling measures chapter stage anchors and updates a mutable ref. Hero begins closed, pauses after fonts settle, then blooms in a 2.4 s flexible rib wave. Anatomy is an assembled object inspector on the left with compact part navigation and a stable detail area. All six part families have live anchored close-ups and their own action: one/all ribs, a linkage cycle, projected runner travel, connected tie tracing, paper-side views and a grip-focused turn. Provide overview reset, optional bounded paper cutaway and explicit ownership between local inspection and page scrolling. Hover must not select or move the camera; reset, replacement and exit must cancel demonstrations. Light presents the underside overhead with a real sun slider and rain switch. Canopy places swatches on the left and the turning umbrella on the right. Making pins its whole composition with native sticky positioning while scroll advances all ten listed steps and the matching component highlights/separation. Keep the complete list and umbrella visible, release the scene only after step 10, and reverse it on upward scroll. Keep a readable unpinned fallback for reduced motion and cramped screens, preserve the active beat on resize and honour direct later-chapter anchors. Commission folds and rests the umbrella on the left beside the form, with a subtle reflection. Do not overlap interactive content with the stage. Mobile uses a fully opaque shared model band above chapter text, with native vertical touch scrolling.

Build the washi, ridges/mist/sun, drafting/asanoha, indigo moon/cloud/rain, sakura/dye, bamboo and dusk/puddle backgrounds in SVG/CSS using only the brand palette. Cross-fade scene layers through the director. Line-mask headings, sharpening text, rolling digits, list rules, swatch rings, magnetic button interiors, press ripples, slider/switch feedback, floating form labels and a success hanko must each have authored motion. Keep default server content visible.

All controls change the model: part hover/focus/click and raycasting link both ways, selection draws a leader, dragging spins with time-based inertia, the runner also has a keyboard slider, sun moves a light/backlight, rain adds streaks/drips/rings, and colourway dyes the paper from the input point. Optional synthesised rain sound starts only from an explicit click, stays off initially even with a saved preference, follows scene intensity, suspends when hidden and cleans up on unmount.

Reduced motion keeps a still open model per chapter and removes intro/spin/parallax/rain/cursor motion; colour changes are instant and sound is independently usable. No-JS retains a static SVG poster and readable content. Keep the form local with descriptive validation. Dispose textures, geometry, materials, timers, listeners, ScrollTriggers and audio nodes. Do not add runtime packages, commit or deploy. Verify the rig, gallery registration, palette/isolation and e2e tests plus defined screenshots; do not run Lighthouse or speed benchmarks.
