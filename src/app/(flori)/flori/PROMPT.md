# Prompt: rebuild "Flori" — a little flower club

Build an isolated Next.js 16 App Router + React 19 + TypeScript + Tailwind CSS v4 landing page at `/flori` for a fictional seasonal flower subscription. Install `npm i next react react-dom lenis`. Read the installed Next documentation before implementing APIs. Keep the complete copy unit inside `src/app/(flori)/`.

The idea: flowers gather stem by stem, so the page lets you compose a bouquet that follows you into signup. Satsuma is a quality reference for playful depth and craftsmanship. Invent the botanical art, geometry and identity from scratch. The mood is airy, playful, tender, sculptural, sunlit. No brutalism, utilitarian styling, halftones, grain, dotted textures, stock imagery, gradients, heavy borders or black.

Palette: cream #FFF9F0 page, fern #344C40 text and actions, blush #F1C6CF, lilac #D8D1EC, pistachio #D9E6C8, butter #F5DF9B, apricot #EDB997, sage #91AAA0. Derive tints with color-mix. Use fern text on pastel backgrounds. Fonts through next/font/google: Lora 500 normal/italic for expressive display, Outfit 400/500/600 for body and labels, Caveat 500 for handwritten notes. Distinct font variables. A six-petal flower beside a lowercase literary `flori` wordmark is the logo; include the SVG favicon and a branded 1200×630 OG image.

Hero: quiet sticky navigation; centered eyebrow; two-line headline "A little bloom. / A brighter day." with the second line italic; two lines of supporting copy; five fanned botanical postcards on pastel backgrounds with different vase silhouettes and original vector cosmos, poppies, daisies and bells. Use rotation ±14 degrees and a shallow arc; center card highest. Handwritten marginal note and a green circular flower seal flank the hero on desktop. A dark fern pill "Find your flowers ↗" sits below the fan. Include the price line "From £24 a bunch · A little joy, on repeat". Keep the complete hero visible on a 1440×900 laptop. On phones crop the fan gracefully to about three postcards without horizontal page overflow.

Sections: scalloped pistachio promise band; weekly gathering with three large illustrated cards (Daydream, Sunbeam, Wild Thing); lilac bouquet composer; asymmetric illustrated club story with heading "Not for a birthday. Not for an apology. Just for living."; pistachio subscription plans; local-only signup; blush oversized typographic footer.

Make the hero postcards a moving carousel: drift continuously at 24px/s and recompute each card's arc height and rotation from its horizontal position. Wrap ten slots outside the viewport, with the second set reusing the original botanical SVG groups via `<use>`, aria-hidden and excluded from keyboard tab order. Pause on hover, focus, hidden tabs, offscreen, and local/global pause controls. Add previous/next buttons, keyboard arrows on the carousel region, and horizontal pointer dragging with restrained release momentum. Focused original cards move into view immediately. With reduced motion, stop autoplay and momentum while keeping manual controls instant. Without JavaScript, retain the original five-card fan. Put tested wrapping and arc geometry in `bouquet/carousel.ts`, with the client controller in `bouquet/PostcardCarousel.tsx`; keep per-frame values out of React state.

Composer: native radio controls for Daydream (pink/lilac), Sunbeam (apricot/butter), Wild Thing (cream/lilac). Sizes little £24, lovely £34, abundant £48. Seven original SVG stem groups gather from their scattered positions as the section enters the viewport; changing the feeling updates the petals and vase. A measured, clamped scroll progress is calculated by a tested pure function. Only CSS custom properties are written in the requestAnimationFrame scroll loop. The CTA preserves feeling and size in `?feeling=sunbeam&size=lovely#join`; collection cards deep-link to the composer. Parse and allowlist query values; defaults are daydream/little. Intercept enhanced hash anchors to scroll to the real section, preserving keyboard, history and modified clicks.

Signup: first name and email, prefilled flower feeling and size. Validate names up to 80 characters, email up to 254 characters, allowlisted choices. Show associated error text, aria-invalid, focus the first invalid field, and animate one gentle shake. Submit visibly prepares then replaces the form with a flower confirmation containing the name and selected bunch. No network request, storage, order placement, or payment. Make its demo status clear. Reset returns to the form and focuses the name field. No-JS shows complete art and an email contact fallback.

Motion identity: gather and unfurl. Build motion tokens first: ease-out cubic-bezier(.22,1,.36,1), expo-out cubic-bezier(.16,1,.3,1), in-out cubic-bezier(.65,0,.35,1), spring linear(0,.5 15%,1.03 50%,1); duration 90/180/420/850/1200ms; stagger 75ms; shift 26px. Choreograph header, masked headline lines, lead, postcard fan, CTA and notes on load. At least four reveals: masks, card cascades, media wipes and drawn rules. Buttons fill-wipe, arrows slide, cards lift, native radios show visible focus. Responsive native dialog navigation with Escape, focus containment and return, and scroll lock. Compact header and progress rail. Dynamically import Lenis only for fine pointers without reduced motion; use native touch scrolling. Ambient movement is limited to leaf sway and a flower turn, paused offscreen, in hidden tabs, and by the footer pause control. No spatial motion, hidden content, ambient loops, or Lenis under reduced motion. No-JS and reduced-motion versions look finished.

Use server page and section components with client leaves for interactions. Split into brand, content, bouquet, motion, forms and sections folders. Include DESIGN.md with a full motion map, this rebuild prompt, media directions and an optional responsive Picture helper.
