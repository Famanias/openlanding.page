# VOLUME ZERO media direction

VOLUME ZERO is approved as a no-photo, no-video template. The page's visual media is procedural WebGPU geometry, SVG diagrams and CSS contour texture. These prompts document the art direction in case a future revision adds stills.

## Style preamble

Post-industrial acoustic observatory, matte vellum and graphite surfaces, crisp technical drafting, measured room geometry, quiet directional light, thin contour lines, restrained signal teal, no text, no logos, no people's faces, no gradients that introduce new hues, no glossy glass, no stock-photo realism, no decorative colour outside graphite `#171B20`, vellum `#F1EEE5`, and signal teal `#2B9BAA`.

## Processing

If these files are ever supplied, place raw originals in `assets/incoming/volume-zero/`, add the slug to `scripts/process-images.ts`, run `npm run images -- volume-zero`, and review the generated contact sheet before replacing the labelled placeholders. The approved page does not depend on them.
