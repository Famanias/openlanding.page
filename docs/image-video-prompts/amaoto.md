# AMAOTO media prompts

AMAOTO uses a procedural Three.js wagasa and code-drawn ink-wash branches, so no external images are required for the template. If a photographic poster is added later, keep the direction warm, overcast and paper-forward: a hand-built wagasa on a neutral grey studio ground, no text, no logos, no people, with visible radial bamboo ribs, translucent washi and a turned wood handle.
