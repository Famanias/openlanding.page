# Media & Schematic Direction: LOOPHOUSE

LOOPHOUSE is designed with **zero stock photograph dependencies**. The template uses precision-machined SVG isometric schematics, CSS perforated pegboard dot grids, and millimeter cutting mat surfaces.

## Style Preamble

- **Aesthetic:** Utilitarian workshop craft, Dieter Rams functionalism, industrial catalog schematics.
- **Palette:** Cast-Iron `#111618`, Birch Paper `#F4EFE6`, Safety Cobalt `#1E51EB`, Galvanized Steel `#7E8A90`, Workshop Pine `#DED7C5`.
- **Rhythm:** Sharp mechanical hairlines, caliper measurement markings, technical dimensional callouts.
