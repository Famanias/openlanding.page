# NIGHTLINE image prompts

No external image keys were available during the diagnostic run, so the template uses labelled placeholders and a raw WebGL2 window. If media is generated later, process it through `npm run images -- nightline` and replace the matching entries in `assets.generated.ts`.

## Style preamble

Quiet European night travel, deep blue window glass, warm amber practical light, rain beads in sharp foreground, city lights soft and out of focus, tactile film grain, restrained editorial photography, no people, no signage text, no logos, no gradients added in UI.

## Assets

- `window-hero`: 16:9, full train window with rain and a distant amber platform.
- `cabin-berth`: 4:3, folded wool blanket, reading lamp, blue glass reflection.
- `cabin-sleeper`: 4:3, private sleeper detail, brass latch and paper ticket.
- `station-lights`: 3:2, platform lights dragging through wet glass.
- `dawn-platform`: 16:9, pale Vienna platform before sunrise, no people.
- `og-base`: 16:9, abstract dark window with one amber rail line.
