# TALLY — Media & Art Direction Prompts

> **Default configuration:** TALLY ships with **100% original coded SVG illustrations** (`src/app/(tally)/tally/brand/Illustrations.tsx`) and requires zero external photos or video files. If you wish to replace or supplement the coded illustrations with generated photography, save raw images to `assets/incoming/tally/` using the filenames below and run `npm run images -- tally`.

## Style Preamble (paste with every prompt)

```
Overhead or three-quarter editorial studio still-life on warm buttercream paper stock (#FAF4E8), accented with soft pistachio mint (#C8E6D0), apricot blush (#F7C8B6), periwinkle lilac (#CFD6F6), and deep plum charcoal ink (#231F2B) details. Crisp natural morning window light, gentle paper grain, tactile workshop objects, perforated paper claim tickets, brass counter hardware, clean negative space. Medium-format 50mm lens, f/5.6. No readable text, no brand logos, no human faces, no neon or glossy plastic.
```
