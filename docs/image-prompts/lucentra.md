# LUCENTRA image prompts

No API keys for image/video generation were detected, and this template is intentionally complete without generated media. If replacement imagery is desired, place the files in `assets/incoming/lucentra/` with the exact names below and run `npm run images -- lucentra` after adding the slug to the processing allowlist.

Style preamble for every prompt: clinical optical still life, pale paper studio, frosted glass and cut acrylic, cobalt signal blue, graphite linework, quiet museum documentation, hard edge highlights, shallow depth of field, no text, no logos, no people's faces.

| Filename | Ratio | Use |
|---|---:|---|
| `hero-specimen.webp` | 4:3 | optional hero poster behind the SVG specimen |
| `bench-detail.webp` | 3:2 | optional calibration bench detail |
| `field-note.webp` | 1:1 | optional field-note texture |

## Prompts

### `hero-specimen.webp`

Style preamble. A single faceted translucent prism on a pale calibration card, three planes visible, cobalt edge light, small registration ticks around the object, centered composition with generous paper margin, no labels or text.

### `bench-detail.webp`

Style preamble. Close optical bench view of a frosted acrylic slab, thin cobalt ray lines crossing the cut, graphite measurement marks, one hard highlight held along the bevel, precise and quiet, no labels or text.

### `field-note.webp`

Style preamble. Macro view of etched glass, a soft spectral band passing through one edge, paper and graphite calibration swatches in the background, restrained blue tint, no labels or text.
