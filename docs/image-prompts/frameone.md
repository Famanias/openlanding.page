# FRAME/ONE — image and preview prompts

These are visual references for a **fictional** director portfolio. All four project titles, categories and credits below are invented for the template; they do not refer to real clients, awards or productions. The paired images for each project should feel like shots from the same scene.

## Output and delivery

- Save the finished stills using the exact names below in `assets/incoming/frameone/`. If your generator exports PNG or JPEG, keep the original files and convert copies to WebP without adding text or borders.
- Film stills: 2.39:1, preferably **2048 × 857 px** or another width between 1800 and 2400 px. Keep the composition legible when cropped to a small contact-sheet frame.
- Behind the scenes: 3:2, preferably **2048 × 1365 px**. Portrait: 4:5, preferably **1600 × 2000 px**. Grain: **1024 × 1024 px**.
- Optional preview loops go in `assets/incoming/frameone/clips/`. They should be silent, 3–5 seconds and matched to the still named in the prompt.
- Do not add film borders, frame numbers, subtitles, watermarks, logos or typography. The interface supplies these separately.
- After the files arrive, the template workflow will process them into responsive 800w and 1600w WebP and AVIF variants, create the asset manifest and present a contact sheet for review. Clips will get desktop and 720p phone encodes.
