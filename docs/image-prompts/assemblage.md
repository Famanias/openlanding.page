# Assemblage media prompts

The template is intentionally code illustrated. If photography is added later, use quiet editorial still life: uncoated paper, translucent acetate, hand cut shapes, ink marks, tape, daylight, generous negative space and no people, screens or readable type. Keep the palette close to paper, ink, sand, vermilion, teal and ochre. Crop at 4:3 for section cards and 16:10 for the hero. The current route uses the CSS collage and `public/templates/assemblage/preview.svg` so the page is complete without a media dependency.
