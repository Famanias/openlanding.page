# LUCENTRA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build and register a complete LUCENTRA landing template from the supplied glass hero.

**Architecture:** A route-group-local Next.js template with a calibration bench state machine, SVG/CSS specimen art, motion primitives, and a client-only local brief form. The desktop bench is sticky and scroll-linked; phone and reduced-motion layouts are stacked and fully readable.

**Tech Stack:** Next.js 16, React 19, TypeScript, Tailwind v4, native CSS motion, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-26-lucentra-design.md`

## Global Constraints

- Use only the LUCENTRA palette and `color-mix()` tints inside the route.
- Keep all imports inside `src/app/(lucentra)/` plus npm packages.
- No network form submission and no generated media dependency.
- Motion must respect reduced motion, no-JS, touch, focus, press, loading, and success states.

## Review Focus

- `bench/state.ts` clamps progress, maps values deterministically, and ignores unknown preset ids; tests cover both bounds.
- `forms/validate.ts` rejects missing and malformed values without echoing raw input into HTML; tests cover valid and invalid submissions.
- The bench is complete in flow mode and reduced motion; e2e checks the range control and all visible readouts.
- All gallery registration points agree on the new slug and preview path; existing template tests remain green.
