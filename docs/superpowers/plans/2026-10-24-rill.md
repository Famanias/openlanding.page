# RILL landing template Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the RILL climate-agriculture landing template to the gallery, centered on an image-led watershed stage where a 0–80 mm rain gauge follows one drop from ridge to root zone.

**Architecture:** A route-group-local Next.js template under `src/app/(rill)/` composes server-rendered sections and client leaves. Generated media is optional and rendered through labelled placeholders; a small external store keeps the shared rain value in sync between the sticky stage, the budget readout, and the header rail. Pure maths and validation modules are tested before their components.

**Tech Stack:** Next.js 16.4.2 App Router, React 19.3, TypeScript, Tailwind CSS v4, native SVG/DOM, `next/font/google`, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-24-rill-design.md`

## Global Constraints

- Route imports remain isolated to `src/app/(rill)/`; do not use `@/` aliases from the template.
- Palette is limited to `#14231E`, `#F0E9DB`, `#B85C43`, `#5B8174`, `#87956C`, `#C9B79E`; tints use `color-mix()`.
- Fonts are Cormorant Garamond, Fira Sans and Fira Mono through `next/font/google`.
- The page must render complete with no JavaScript, with `prefers-reduced-motion: reduce`, without media files, and at 390px.
- Motion identity is organic / analog with the verbs trace and settle; animate transforms, opacity, clip-path and SVG stroke offsets only.
- User-generated media is optional and must be documented in `docs/image-prompts/rill.md`; never add a secret or key value.
- Run `npm run check`, `npm test`, `npx tsc --noEmit`, and the RILL Playwright spec before completion.

## Review Focus

- Scroll progress near section bounds must clamp to 0/1 and never divide by zero; test in the math task.
- Rain input and scroll can update the same store without feedback loops; test store synchronization and the 42 mm phase transition.
- Reduced-motion and no-JS users must see the entire watershed story and all final values; test in the e2e task.
- Invalid form input must show field-specific errors and never report success; test validation and the e2e form flow.
- Missing images/clips must preserve aspect ratios and accessible names; test `Picture`/`VideoPlate` rendering and the e2e placeholder path.
